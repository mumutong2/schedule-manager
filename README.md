# 日程安排程序（C 语言课程设计）

一个运行在 Windows 命令行下的个人日程管理工具，纯 C 语言实现，数据保存在本地文本文件中，不依赖任何第三方库。

大一上学期《C 语言程序设计》课程设计作业，独立完成，代码 314 行。

## 功能

| 序号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 添加 | 输入「年 月 日 内容」，追加一条日程 |
| 2 | 删除 | 按日期列出当天所有日程，输入编号删除单条，输入 0 删除当天全部 |
| 3 | 修改 | 按日期列出当天所有日程，选择编号后输入新内容 |
| 4 | 提醒 | 查看今天（自动读取系统时间）或指定日期的全部日程 |
| 5 | 关闭 | 退出程序 |

同一天可以保存多条日程；每个操作结束后都会回到主菜单，各子功能都支持「输入 0 或 -1 返回上一级」。

## 运行

需要 gcc 或任意 C 编译器：

```
gcc main.c -o richenganpai.exe
richenganpai.exe
```

仓库里也带了 Code::Blocks 工程文件（`richenganpai.cbp`），双击打开即可编译运行。

> **注意**：`data.txt` 必须和可执行文件放在同一目录。程序的删除、修改、提醒三个功能都以「读」的方式打开它，文件不存在时不会自动创建，会直接读到空指针。

## 数据格式

每行一条日程，格式为 `年 月 日:内容`：

```
2025 12 20:firstday
```

每行用 `sscanf(line, "%d %d %d:%[^\n]", &y, &m, &d, anpai)` 解析。解析失败的行会被**原样写回**，不会因为混进一行脏数据就让整个文件报废。

## 实现要点

- **删除 / 修改用「临时文件 + 重命名」整体重写**：先把保留的行写到 `temp.txt`，关闭两个文件句柄，再 `remove` 原文件、`rename` 临时文件。整个过程不就地覆盖，写到一半出错也不会把原数据写坏。
- **修改内容用 `fgets` 读整行**，再用 `strcspn(newanpai, "\n")` 去掉换行符，所以日程内容可以带空格（`%s` 读到空格就停了）。
- **删除 / 修改前先扫描一遍**，把当天日程编号后打印出来供用户选择，避免"删错行"；当天没有日程时直接跳回输入日期那一步，不用重新走菜单。
- **重写前加 100ms 延迟**（`Sleep(100)`），等文件句柄释放后再 `remove`，否则 Windows 上会遇到文件被占用导致重命名失败。
- 非法输入（菜单输入 1~5 以外的数字）会提示并重新等待输入，不会进入错误分支。

## 已知不足

- 日程数组是全局定长的 `lines[100][200]`，最多 100 条、每条 200 字节，超出会被截断。
- 删除和修改都要重新扫描整个文件，数据量大时效率不高，也没有做内存索引。
- 没有校验日期合法性，`2026 2 30` 这样的日期也能写进去。
- `system("cls")` 和 `Sleep()` 是 Windows 专用，换到 Linux/macOS 需要替换。

以上都是课程设计阶段时间有限留下的问题，也是后面想重写一遍的原因（换成链表存数据 + 按日期建索引 + 跨平台清屏）。
